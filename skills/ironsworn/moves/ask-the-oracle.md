# Ask the Oracle

**Trigger:** You need to resolve a question about the world, an NPC's response, or a discovery.

---

## Choosing the Right Oracle

**Use the right tool for the question type:**

| Question type | Oracle to use |
|---|---|
| What happens? (event, random event, plot turn) | `solo-roll meaning-pair` (action + theme) |
| Yes or no about a fact? | Yes/No table below (or `solo-roll fate-check` if Mythic is loaded) |
| What does this place/thing look/feel/sound like? | `solo-roll table elements/terrain` (or location, sound, smell, descriptor) |
| NPC name? | `solo-roll table ironsworn/names` |
| Plot complication? | `solo-roll table elements/plottwist` or meaning-pair |

**Do not use meaning-pair for atmosphere or description.** An action+theme pair reads as an event, not sensory detail.

---

## Ask a Yes/No Question

Decide the odds of "yes," then roll 2d10 using `solo-roll roll 2d10`. If both dice match, an extreme result or twist has occurred.

| Odds | Answer is "yes" if you roll... |
|---|---|
| Almost Certain | 11 or greater |
| Likely | 26 or greater |
| 50/50 | 51 or greater |
| Unlikely | 76 or greater |
| Small Chance | 91 or greater |

---

## Approaches

**Draw a conclusion:** Decide the answer based on the most interesting and obvious result.

**Ask yes/no:** Decide odds, roll on the table above.

**Pick two:** Envision two options. Rate one "likely," roll to see if it is true. If not, it is the other.

**Spark an idea:** Roll meaning-pair or elements table for a random prompt.

---

Tell the player what you rolled and what you rolled on. Transparency is the point. Do not re-roll until you get something you like — unexpected results are where solo play gets interesting.
